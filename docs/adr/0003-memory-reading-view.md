# 0003 记忆阅读面复用宿主右侧栏：自定义参数页签 + 原生分屏文件预览

- 状态：已被 [ADR-0004](0004-memory-detail-in-panel-native-open.md) 取代（preview.16 撤回侧栏双窗格，改为面板内弹窗 + 系统应用打开；本文件保留作决策历史）
- 日期：2026-11-10
- 背景：`dsh-agent-extension` 的记忆详情只有编辑弹窗内的一个 `<textarea>`，正文以 Markdown 源码示人，阅读体验差；同时记忆以阅读为主、由智能体随会话自动维护。宿主内置的 `MarkdownText`/`DetailDocument` 没有给第三方插件的 ctx 或 slot 通道，直接导入又撞本仓库的 purity 门禁与「禁止 import `@deepseek-ai/*`」规则。规格见 [`packages/dsh-agent-extension/docs/memory-reading-view.spec.md`](../../packages/dsh-agent-extension/docs/memory-reading-view.spec.md)。

## 决策

1. **阅读面交给宿主右侧栏的文件预览**：记忆条目打开为宿主 md 预览页签，由宿主的 `MarkdownText` 渲染，只读。插件不自造 Markdown 渲染器、不引第三方解析库、不破 purity 门禁。
2. **参数面用宿主侧栏的第三方扩展点**：插件注册一个 `priority: 'extension'` 的自定义页签（键控槽 `sidebar.right.pane.tab`），自绘元信息表单与状态动作；页签标题与 body 的 key 均等于注册 id。
3. **双列用原生分屏**：打开参数页签后，以 `openResource(地址, { preferNewPane: true })` 让宿主把预览页签放进第二个窗格；宽度不足或已达窗格上限时由宿主回退到同窗格添加页签，用户手动切换。
4. **裁剪阅读数据**：预览不直接喂记忆原文件（frontmatter + 正文），而是由宿主半按条目生成「仅正文」的一次性 Markdown 临时文件，避免 YAML 头被当正文渲染。
5. **正文只读、元信息可调**：宿主预览没有编辑面，因此 v1 不做正文人工编辑（宿主能力支持则沿用，不支持则不做）；名称/描述/类型/标签/重要性/状态在参数页签内有限调整。新建记忆仍保留写正文的弹窗。
6. **面板切换是已知代价**：主面板激活时宿主右侧栏不挂载，打开详情必须先 `ctx.layout.selectPanel(null)` 退回工作台；无前台 Session 时给出明确提示并回退到插件面板。

## 理由

- 用户要的"右侧复用现有 md 预览、左侧看参数"正好对应宿主侧栏的两个原生能力（自定义页签 + 文件预览 + 分屏），不需要自建渲染与浮层，也不改动宿主侧栏的既有行为。
- 宿主预览是产品内既有的 Markdown 阅读体验，主题 token、代码块、表格渲染天然一致；自造渲染器既要长期维护，又与"官方克制观感"的基准背离。
- 记忆文件一事实一文件、正文为 Markdown（见 ADR-0001），把它作为预览的真实来源最贴近"记忆即文档"的领域模型；临时文件只是剥离 frontmatter 的读侧投影。

## 放弃的方案

- **弹窗内打包 `marked` 映射 React 元素**：能保住弹窗交互，但引入第三方运行时代码进产物、要长期维护一套 Markdown 样式，且与宿主观感不一致。
- **直引 `ui-primitives` 的 `MarkdownText`**：观感最贴且可留在弹窗，但需修改 `tsdown.config.ts` 的 purity 门禁并破 `AGENTS.md` 硬规则与 `PLUGIN-DEV §3.5`，合规成本不可接受。
- **常驻 overlay 浮层做参数面**：`shell.overlay` 确实不随主面板卸载，但浮层叠在聊天之上是宿主不存在的交互范式，且遮罩会阻断右侧预览的滚动与交互。
- **只保留现有弹窗、在弹窗内加只读区**：不解决 Markdown 渲染，等于没解决问题。
- **把整个记忆页搬进右侧栏**：记忆管理是面板内任务，整页迁移会破坏列表、筛选、新建与设置等既有工作流。

## 后果

- 点击记忆条目会离开「智能体扩展」面板回到工作台，右侧栏出现"参数页签 + 预览页签"；返回列表需重新点侧栏入口。这是规格明确接受的交互代价。
- 详情面依赖前台 Session 与宿主侧栏 API（pre-stable，无兼容承诺）：宿主升级后必须回归；若 API 失效，回退为"现有弹窗、无预览"，不硬性维持。
- 数据面新增 `/memory/preview-file` 与系统临时目录的预览文件（按 id 覆盖、7 天清理、删除时清理），不改变记忆库格式，无需数据迁移。
- 正文在创建后不可人工修改（可重新新建或用外部工具改文件）；如后续宿主开放渲染/编辑通道，阅读面可平移，数据面不变。
- 侧栏布局按 Session 持久化，重载后预览页签可能指向被清理的临时文件；页签挂载时重写预览文件即可恢复。
